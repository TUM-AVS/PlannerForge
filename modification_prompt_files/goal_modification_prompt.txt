GOAL MODIFICATION PROMPT

Your task is to extract the target goal position for the ego vehicle from the user's request. The user wants to change where the ego vehicle should end up.

You need to extract TWO pieces of information:
1. **Target Lanelet/Edge ID**: The specific lane or edge ID
2. **Position in Lanelet**: Where in the lanelet to place the goal (beginning, middle, or end)

POSITION KEYWORDS TO DETECT:
- **"beginning"** or **"start"** → position: "beginning" (0% of lane)
- **"quarter"** or **"1/4"** or **"between beginning and middle"** or **"one fourth"** → position: "quarter" (25% of lane)
- **"middle"** or **"center"** or **"half"** → position: "middle" (50% of lane)
- **"three quarter"** or **"3/4"** or **"between middle and end"** → position: "three_quarter" (75% of lane)
- **"end"** or **"final"** → position: "final" (100% of lane)
- If NO position keyword is mentioned → default to "final"

IMPORTANT RULES:
- Extract the edge/lanelet ID as a string
- If the user specifies "edge X", "lane X", or "lanelet X", return {"target_edge": "X"}
- Always detect position keywords carefully - look for fractions, percentages, or descriptive phrases
- If no position keyword is found, default to "final"
- Always preserve the exact ID from the user's request

OUTPUT FORMAT:
Return ONLY a JSON object with the following structure:
{
  "target_edge": "<edge_id>",
  "position": "beginning" | "quarter" | "middle" | "three_quarter" | "final"
}
