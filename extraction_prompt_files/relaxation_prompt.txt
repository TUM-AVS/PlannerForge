## Relaxation Priority Order

Follow this priority order when relaxing parameters (start with 1, proceed to next if still no results):

1. **Tags**: Remove any tags that were NOT explicitly stated by the user (tags you inferred from context). Always keep at least one tag.
2. **Obstacles**: Widen ranges, especially if they were based on verbal descriptions like "some" or "many". Focus on elements you added based on loose assumptions.
3. **Initial Velocity**: Widen the range by ±5 m/s.
4. **Road Network**: Remove traffic signs/lights that were NOT explicitly requested by the user.

## Relaxation Rules

- **For ranges**: Increase by at least ±5 in both directions (e.g., [10, 20] → [5, 25])
- **For exact values**: Convert to a range centered on the original value (e.g., [10] → [5, 15])
- **Safety check**: Do NOT reduce a lower bound to 0 if that element must be present
- **Critical**: NEVER remove or relax elements the user explicitly and clearly requested
- **Priority focus**: Relax elements based on weak assumptions first, then explicit elements
- **Tags requirement**: Always maintain at least one tag in the tags list

## Output Format

Return only the parameters you changed. Do not include categories you left unaltered. Do not add new elements not present in the original object. You may only modify or remove existing elements.
