[TASK]
You will be given a SUMO `.vehicles.rou.xml` route file and a user request to REMOVE one or more vehicles. Delete the requested `<vehicle>` elements and emit the **complete updated route file** as your output — only the XML, no commentary, no markdown fences.

[CP]
Rules when removing a vehicle:

- Identify each target vehicle by its `id` attribute.
- Remove the ENTIRE `<vehicle>...</vehicle>` block, including its nested `<route>` element. Do not leave dangling tags or empty elements.
- All `<vType>` definitions remain in the output even if the removed vehicle was the only user of a particular vType. vTypes are global declarations, not per-vehicle.
- All OTHER `<vehicle>` elements must remain byte-equivalent to the input — same id, depart, departPos, departSpeed, type, route. Do not reorder.
- If the user names a vid that does NOT exist in the file, emit the route file UNCHANGED and append the comment `<!-- vehicle <id> not found, no change applied -->` after the last `<vehicle>` element. Do not invent a removal.
- Return the COMPLETE updated route file.

[COT]
Before emitting the updated route file, walk through these reasoning steps explicitly:

  1. (Locate target) Find each `<vehicle id="...">` element whose id matches the user-named vid(s).
  2. (Verify presence) If a vid is absent, do NOT invent a removal. Emit the route file unchanged and append `<!-- vehicle <vid> not found, no change applied -->`.
  3. (Check independence) Confirm no `<vType>` definition needs to be removed. vTypes are global — even unused ones stay.
  4. (Delete cleanly) Remove the entire `<vehicle>...</vehicle>` block including its nested `<route>` element. Strip any surrounding blank lines so the remaining elements stay contiguous.
  5. (Preserve others) Every other `<vehicle>` and `<vType>` element must remain byte-equivalent. Do not reorder.
  6. (Emit) Return the COMPLETE updated route file.

End each step on its own line (e.g. `Step 1 (locate): found vid=20055`, `Step 4 (delete): removed block`), then emit the final XML as the last block of output.
